
# NuCamp Web Development Training Project

## Overview

This project is a website developed as part of the NuCamp web development training program. It serves as a practical showcase of the knowledge, skills, and techniques acquired throughout the course, with a focus on building structured, responsive, and maintainable web pages.

The project demonstrates the use of HTML for content structure, SCSS (Sass) for styling, Bootstrap for responsive layouts and reusable UI components, and Git for version control. It also introduces a modern front-end development workflow that includes compiling stylesheets and organizing project assets.

## Learning Objectives

- Build semantic and accessible web pages using HTML5.
- Apply modern styling principles using SCSS/Sass rather than writing traditional CSS directly.
- Use SCSS features such as variables, nesting, and reusable style rules to improve maintainability.
- Create responsive layouts and interfaces with Bootstrap.
- Organize images, videos, stylesheets, and other project resources into a clear directory structure.
- Track changes, manage revisions, and maintain project history using Git.
- Understand the role of front-end development tools and generated build files.

## Technologies and Tools

- **HTML5** — Structures page content and semantic elements.
- **SCSS/Sass** — Provides an enhanced stylesheet authoring workflow; SCSS is compiled into browser-compatible CSS.
- **Bootstrap** — Supports responsive grids, layouts, utilities, and reusable interface components.
- **Git** — Tracks changes and supports version control throughout development.
- **Parcel** — Development and build tooling, where configured in the project, for processing assets and generating production output.
- **Visual Studio Code** — Code editor used to develop and manage project files.

## Styling Approach: SCSS Instead of Traditional CSS

SCSS is a syntax of Sass that extends CSS with features designed to make styles easier to organize and maintain. The browser does not interpret SCSS directly, so the source files must be compiled into CSS.

Benefits of using SCSS include:

- **Variables:** Reuse colors, font sizes, spacing values, and other design tokens.
- **Nesting:** Group related selectors for clearer organization.
- **Reusable patterns:** Use mixins and functions when appropriate.
- **Maintainability:** Keep source styles structured as the project grows.

For example:

```scss
$primary-color: #0d6efd;

.site-heading {
  color: $primary-color;
  font-weight: 700;

  &:hover {
    color: darken($primary-color, 10%);
  }
}
```

The SCSS compiler or configured build tool transforms the source into CSS that browsers can render. The exact compilation workflow depends on the project's configuration.

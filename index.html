This project portfolio showcases the web development skills acquired through practical experience with technologies such as HTML, CSS, and Bootstrap, using Visual Studio Code as the development environment. It also demonstrates the application of Git for version control and project management.

Furthermore, the project provides hands-on experience with deploying a completed web application to the internet using Firebase. It highlights the key steps, tools, and techniques involved in preparing, managing, and publishing a web project, demonstrating the practical application of web development concepts from the initial stages of development to final deployment.

The purpose of this project is to demonstrate and apply the knowledge, skills, and practical experience we have gained throughout the bootcamp. It provides an opportunity to put what we have learned into practice, showcase our understanding of the concepts covered, and demonstrate our ability to use these skills to develop practical solutions to real-world problems.

Going forward, I intend to enrol in a more advanced programme to build on my existing knowledge and skills. This will ensure continuity in my learning, deepen my expertise, and support my ongoing professional growth and career development.
